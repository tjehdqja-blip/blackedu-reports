# 매쓰클랜 학원 로고 수집 연결

기존 2기·3기 신청서와 응답 저장 기능을 유지하며 로고를 추가한다.
파일은 GitHub가 아닌 운영자 Google Drive에 저장한다. 직접 첨부는 1개·10MB 이하,
더 큰 원본은 다운로드 가능한 HTTPS 링크로 받는다. 이메일 버튼은 첨부파일을 자동 추가하지 않는다.

## 기존 Apps Script 연결

1. 기존 접수용 Apps Script 프로젝트에 `mathclan-logo-upload.gs` 내용을 새 파일로 추가한다.
2. 준비된 통합본을 사용하면 `setupLogo`를 한 번 실행한다. 운영자 Drive에 비공개
   ‘매쓰클랜 학원 로고’ 폴더를 만들고 빠진 시트 열을 오른쪽에 추가한다.
   기존 폴더를 사용하려면 스크립트 속성 `MATHCLAN_LOGO_FOLDER_ID`에 해당 폴더 ID를 먼저 설정한다.
3. 기존 `doGet(e)`의 첫 부분에 다음을 넣는다. 기존 doGet이 없으면 이 분기를 반환하는 함수를 추가한다.

   ```js
   var logoResponse = mathclanLogoGet(e);
   if (logoResponse) return logoResponse;
   ```

4. 기존 `doPost(e)`의 첫 부분에 다음을 넣고, 기존 신청서 저장 코드는 그대로 유지한다.

   ```js
   var logoResponse = mathclanLogoPost(e);
   if (logoResponse) return logoResponse;
   ```

5. 기존 응답 저장 코드가 다음 필드도 실제로 기록하는지 확인한다.
   고정 헤더·열 매핑을 사용하면 해당 열을 추가하되 기존 열과 응답은 보존한다.

   - 로고 제출 방법
   - 로고 파일 링크
   - 로고 파일명
   - 로고 용량(바이트)

6. 수집은 Drive 저장과 시트 링크 기록으로 진행한다. 이메일은 자동 발송하지 않는다.
7. 운영자 권한으로 Drive 접근을 승인하고 기존 웹 앱을 새 버전으로 업데이트한다.
   실행 주체·접근 대상·실행 URL은 기존 신청서 설정을 유지한다.
8. 외부 브라우저에서 `?action=logoCapabilities`가 `mathclan-logo-v1`을 반환하는지 확인한다.
   파일 선택은 이 확인이 성공해야 활성화된다. 실패하면 링크·추후 이메일 제출만 제공한다.
9. 테스트 신청 1건으로 Drive 파일 내용, 시트의 파일 링크와 신청자 연결, 비공개 권한,
   실제 저장 여부까지 검증한 후 페이지를 배포한다. 테스트 자료는 별도로 정리한다.

로고 업로드 실패 시 신청서는 그대로 남고 재시도나 링크·추후 이메일 제출을 선택할 수 있다.
같은 파일을 재시도하면 요청 ID로 중복 저장을 방지한다. 신청서 저장 실패 시 이메일 대체 내용에도
이미 저장된 로고 링크가 포함된다. 폴더 업로드는 하루 100개로 제한한다.

## 현재 검증 범위

로컬 브라우저에서 업로드 성공·실패, 대용량 및 형식 검증, 링크·이메일 대체 경로를 확인한다.
실제 Apps Script 수정·배포와 응답 시트 열 매핑 검증은 기존 프로젝트 접근 후 진행해야 한다.
